# User Tips & Best Practices

## Form Submissions

- Submit buttons remain inactive until all required fields (marked with \*) are properly filled
- Check for validation messages that appear in red when fields are incorrectly filled
- Required fields must be filled before proceeding:
  - Text fields should not be empty
  - Numbers should be within valid ranges
  - Dates should be in correct order (start date before end date)
  - Coordinates should be in proper format

## Account Security

- Always log out of your account when:
  - Using shared computers
  - Using public devices
  - Finishing your work session
  - Leaving your workspace
- Click the "Logout" button in the top right corner of the screen
